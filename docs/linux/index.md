# 🐧 Linux

Module sur l'administration des systèmes Linux (Debian/Ubuntu, RHEL/CentOS, Arch).

## Modules du cours

| Thème | Description |
|-------|-------------|
| [[installation]] | Installation, partitions, GRUB, initramfs |
| [[administration]] | Gestion de paquets, fichiers, processus, utilisateurs |
| [[services]] | systemd, réseaux, services, logs |
| [[scripting]] | Bash scripting, cron, automation |
| [[sécurité]] | SSH, pare-feu, SELinux/AppArmor, hardening |

## Objectifs pédagogiques

- Installer et configurer une distribution Linux
- Maîtriser la gestion des paquets (APT, DNF, Pacman)
- Administrer les services avec systemd
- Écrire des scripts Bash
- Appliquer les bonnes pratiques de sécurité

## Distributions étudiées

| Distribution | Usage | Gestionnaire |
|-------------|-------|--------------|
| Ubuntu Server | Standard TSSR | APT (.deb) |
| Debian | Serveur stable | APT (.deb) |
| RHEL/Rocky | Entreprise | DNF (.rpm) |
| Arch | Avancé | Pacman |

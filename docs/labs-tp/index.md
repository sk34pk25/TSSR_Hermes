## Environnement de labs

### Matériel recommandé

- CPU : 4 cœurs minimum
- RAM : 16 Go minimum
- Stockage : 100 Go SSD minimum
- Réseau : 2 cartes réseau (bridge + interne)

### Hyperviseur

- VMware Workstation/ESXi
- Hyper-V Server
- Proxmox VE
- VirtualBox

## Structure d'un lab

```
Lab 01 - Configuration réseau

├── Prérequis
├── Topologie
├── Étapes de réalisation
├── Vérifications
└── Questions de synthèse
```

# ⌨️ Commandes Utiles

Référence rapide des commandes essentielles pour les administrateurs TSSR.

## Commandes par plateforme

| Plateforme | Commandes disponibles |
|------------|----------------------|
| [[windows]] | PowerShell, CMD, Netsh |
| [[linux]] | Bash, systemctl, réseau |

## Commandes transverses

- **Réseau** : ping, traceroute, nslookup, dig, netstat
- **Système** : top, htop, iotop, nmon
- **Logs** : journalctl, grep, awk, sed

# 🌐 Réseaux

Module de référence sur les fondamentaux et l'administration des réseaux informatiques.

## Modules du cours

| Thème | Description |
|-------|-------------|
| [[fondamentaux]] | Modèle OSI, TCP/IP, protocoles |
| [[adressage]] | Adressage IPv4/IPv6, subnetting, VLSM |
| [[routage]] | Routage statique et dynamique (RIP, OSPF, BGP) |
| [[vlan-switching]] | VLAN, 802.1Q, STP, LACP |
| [[services]] | DNS, DHCP, SNMP, NTP |

## Objectifs pédagogiques

- Comprendre le modèle OSI et son application pratique
- Maîtriser l'adressage IP et le subnetting
- Configurer et dépanner des protocoles de routage
- Mettre en œuvre VLAN et switching
- Déployer les services réseau essentiels

## Prérequis

- Connaissances de base en informatique
- Accès à un environnement de labs (GNS3, EVE-NG, ou VMware)

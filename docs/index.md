# 🎓 TSSR 2026-2027 — Technicien Supérieur Systèmes & Réseaux

Bienvenue dans la documentation officielle de la formation **TSSR** (Technicien Supérieur Systèmes & Réseaux) pour l'année 2026-2027.

## 📋 Présentation de la formation

La formation TSSR forme des techniciens supérieurs capables de concevoir, déployer et administrer des infrastructures IT complètes, incluant :

- **Administration système** : Windows Server et Linux
- **Administration réseau** : Routage, switching, VLAN, services réseau
- **Cybersécurité** : Hardening, pare-feu, tests d'intrusion
- **Virtualisation** : Hyper-V, VMware
- **Automatisation** : Scripts, Ansible, monitoring

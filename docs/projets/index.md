## Structure d'un projet

Chaque projet suit cette structure :

1. **Contexte** : Description de la situation
2. **Objectifs** : Ce qui doit être réalisé
3. **Livrables** : Ce qui doit être rendu
4. **Barème** : Points attribués
5. **Ressources** : Documentation utile

# 🪟 Windows Server

Module sur l'administration des serveurs Windows Server 2022/2025.

## Modules du cours

| Thème | Description |
|-------|-------------|
| [[installation]] | Installation, editions, configuration initiale |
| [[active-directory]] | AD DS, forêt, domaines, unités d'organisation |
| [[gpo]] | Group Policy Objects, héritage, filtrage |
| [[dns-dhcp]] | Serveur DNS et DHCP Windows |
| [[hyper-v]] | Virtualisation Hyper-V, clusters |

## Objectifs pédagogiques

- Installer et configurer Windows Server 2022/2025
- Déployer un contrôleur de domaine Active Directory
- Créer et gérer des GPO
- Configurer DNS et DHCP sur Windows Server
- Mettre en place la virtualisation Hyper-V

## Prérequis

- Connaissances de base en administration Windows
- Accès à un environnement de labs avec hyperviseur

# Module 1 - Le modèle OSI

> **Module : Base des réseaux**

## Présentation

Ce module propose des activités pratiques basées sur trois fichiers Packet Tracer (.pka).

## Activités disponibles

Trois activités pratiques sont identifiées :

1. **[M01-01](../../../travaux-pratiques/base-des-reseaux/module-01/M01-01.md)** — Topologie réseau brute (sans consignes intégrées)
2. **[M01-02](../../../travaux-pratiques/base-des-reseaux/module-01/M01-02.md)** — Topologie avec connexions définies (sans endpoints exploitables)
3. **[M01-TP02 - Interconnexion](../../../travaux-pratiques/base-des-reseaux/module-01/M01-TP02-Interconnexion.md)** — TP complet avec instructions, câblage et paramètres Wi-Fi

## Avertissement important

Les sources disponibles (les trois fichiers .pka) **ne contiennent aucun cours théorique sur les 7 couches OSI**. Elles proposent uniquement des activités pratiques sur :
- l'interconnexion physique des équipements
- le câblage (cuivre, fibre, sans fil)
- la configuration Wi-Fi de base
- la méthodologie de vérification dans Packet Tracer

Aucune des 7 couches du modèle OSI n'est explicitement mentionnée dans les sources.

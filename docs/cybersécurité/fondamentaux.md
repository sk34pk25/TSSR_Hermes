# 🛡️ Fondamentaux de la Cybersécurité

## Triade CIA

| Principe | Description | Exemple |
|----------|-------------|---------|
| **Confidentialité** | Seuls les autorisés accèdent aux données | Chiffrement, ACL |
| **Intégrité** | Les données ne sont pas modifiées | Hash, signatures |
| **Disponibilité** | Les services sont accessibles | Redondance, RAID |

## Menaces et vulnérabilités

### Types de menaces

| Menace | Description |
|--------|-------------|
| **Malware** | Logiciel malveillant (virus, ransomware, trojan) |
| **Phishing** | Hameçonnage par email |
| **DDoS** | Déni de service distribué |
| **MITM** | Intercepton de communications |
| **Brute Force** | Attaque par force brute |
| **SQL Injection** | Injection de code SQL |
| **XSS** | Cross-Site Scripting |

### Vulnérabilités courantes

- Mots de passe faibles
- Services non patchés
- Configurations par défaut
- Ports ouverts inutiles
- Chiffrement absents

## Analyse des risques

```
Risque = Menace × Vulnérabilité × Impact

1. Identifier les actifs
2. Identifier les menaces
3. Évaluer les vulnérabilités
4. Calculer l'impact
5. Définir les traitements
```

## Traitement des risques

| Traitement | Description |
|------------|-------------|
| **Éviter** | Supprimer la source du risque |
| **Réduire** | Appliquer des contrôles |
| **Transférer** | Assurance, outsourcing |
| **Accepter** | Risque minime ou coût trop élevé |

## Gouvernance de sécurité

- **Politique de sécurité** : Document directeur
- **Procédures** : Étapes pour implémenter la politique
- **Normes** : Règles techniques contraignantes
- **Lignes directrices** : Recommandations
